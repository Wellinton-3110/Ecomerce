# 🛒 E-commerce

Projeto de E-commerce desenvolvido com foco em aprimorar conhecimentos em desenvolvimento Full Stack, integrando front-end, back-end e banco de dados em uma aplicação completa.

## 🚀 Demonstração

Acesse o projeto e explore as funcionalidades disponíveis.

> ⚠️ **Importante:** Como a aplicação utiliza serviços hospedados em planos gratuitos, o primeiro carregamento pode levar alguns segundos. Isso acontece porque alguns serviços entram em modo de inatividade quando ficam sem uso por um período. Após a inicialização, a navegação ocorre normalmente.

---

## ✨ Funcionalidades

* Cadastro de usuários
* Login e autenticação
* Listagem de produtos
* Consulta de informações dos produtos
* Integração entre front-end e back-end
* Consumo de API REST
* Persistência de dados em banco de dados
* Interface responsiva

## ⚙️ Como Executar o Projeto Localmente

### 1. Clone o repositório

```bash
git clone https://github.com/Wellinton-3110/Ecomerce.git
```

### 2. Acesse a pasta do projeto

```bash
cd Ecomerce
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Configure as variáveis de ambiente

Crie um arquivo `.env` com as credenciais necessárias para conexão com a API e o banco de dados.

Exemplo:

```env
DATABASE_URL=sua_url_do_banco
SUPABASE_URL=sua_url_supabase
SUPABASE_KEY=sua_chave_supabase
```

### 5. Inicie a aplicação

```bash
npm start
```

ou

```bash
npm run dev
```

Dependendo da configuração do projeto.
